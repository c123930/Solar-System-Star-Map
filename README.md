# 太阳系动态星图 · HELIOS Solar Atlas

一个无依赖的交互式太阳系星图。以 Canvas 2D 绘制实时轨道，配合 Kepler 近似星历、完整天体目录、统一详情档案和人类深空探测足迹。

## 运行

直接双击 `index.html`，或在本目录启动任意静态文件服务：

```powershell
# 任选其一
start index.html
npx serve .
```

页面不依赖网络字体、CDN 或构建工具。

## 主要交互

- **全景视图**：恢复太阳系默认黄道视角，清空筛选并退出深空模式。
- **天体分类**：按恒星、行星、卫星、星环、小天体与人类造物检索；支持天体目录折叠与全字段搜索。
- **轨道设置**：独立控制轨道线、轨道参数标注、天体标签、运行拖尾、小行星带、人类造物和星环系统。
- **时间控制**：六档模拟速率（0.25×–365×）、暂停/继续、前进一日、回到此刻。
- **深空足迹**：以夸大的径向尺度展示旅行者、先驱者、新视野号等人造天体的飞行轨迹与任务卡。
- **画布**：拖拽旋转视角，滚轮缩放，点击任意天体打开详情；触屏支持双指缩放。
- **详情面板**：基础档案、轨道参数与轨道线图示、结构特征、探索记录四段式档案。

快捷键：`/` 聚焦搜索，`Space` 暂停/继续，`Esc` 关闭弹层。

## 内容规模

- 1 颗中心恒星
- 8 颗行星
- 10 颗重点卫星
- 4 套行星环系统
- 4 个主带/周期彗星重点小天体与 2 个著名陨石
- 11 项人类空间造物

## 文件

- `index.html`：页面结构
- `styles.css`：视觉系统与响应式布局
- `data.js`：40 份天体档案与分类数据
- `app.js`：轨道计算、Canvas 渲染、交互与详情系统
- `preview.png`：首屏预览图

## 模型说明

行星位置采用 J2000 轨道根数与 Kepler 方程近似求解，周期和相位随模拟时间实时演进。为在一屏中同时呈现内行星与外行星，轨道径向距离经过对数压缩，界面中以 `LOG SCALE` 标注；偏心率和轨道倾角仍参与轨道形状计算。
